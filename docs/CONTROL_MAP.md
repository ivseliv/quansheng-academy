# Карта заводского управления UV-K5

Основа: заводские брошюры M1/M3; ссылки и оговорки находятся в [SOURCES.md](SOURCES.md). Это спецификация выбранного заводского профиля, составленная до реализации. Имена меню сохранены как на устройстве; русские объяснения написаны для тренажёра.

## Физическая панель

Сверху слева антенна, справа регулятор питания/громкости; рядом фонарь. Под LCD слева вертикально расположены M, ▲, ▼, EXIT; справа — решётка динамика. Ниже клавиши идут **четырьмя столбцами и тремя рядами**, а не обычной телефонной сеткой:

| 1-й столбец | 2-й      | 3-й        | 4-й           |
| ----------- | -------- | ---------- | ------------- |
| 1 / Band    | 2 / A/B  | 3 / VFO/MR | * / SCAN      |
| 4 / FC      | 5 / NOAA | 6 / H/M/L  | 0 / FM        |
| 7 / VOX     | 8 / R    | 9 / Call   | F / # / замок |

На левой грани крупная PTT, под ней SK1, затем SK2. Надпись F и символ # относятся к одной физической клавише. Для DTMF M/▲/▼/EXIT соответствуют A/B/C/D; это не самостоятельные четыре режима управления. [M1, Radio Diagram, с. 02 и Keypad Key, с. 04–05](https://github.com/dkxce/Quansheng-UV-K5/blob/main/UV-K5%20manual%202023.02.17%282%29.pdf).

## Короткие, долгие и составные действия

| Орган                       | Действие                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Регулятор                   | Поворот по часовой стрелке через щелчок включает, далее увеличивает громкость; обратно выключает.             |
| PTT                         | Удержание — передача, отпускание — приём; в приложении только учебное состояние TX.                           |
| SK1 коротко                 | Monitor: открыть приём независимо от тоновой фильтрации; позволяет услышать шум и подобрать громкость.        |

| SK2 коротко                 | Фонарик.                                                                                                      |
| SK2 долго                   | Alarm; выход любой клавишей.                                                                                  |
| M коротко на главном экране | Вход в меню. W1 уточняет начало с 01.                                                                         |
| M долго на главном экране   | Последний использованный пункт.                                                                               |
| M в меню                    | Вход в редактирование, затем подтверждение нового значения.                                                   |
| EXIT                        | Отмена несохранённой правки, на уровень выше; при цифровом вводе очистка.                                     |
| EXIT долго                  | Вернуться к основному экрану.                                                                                 |
| ▲ / ▼                       | VFO: один STEP; MR: предыдущая/следующая заполненная ячейка; меню: пункт/значение; сканирование: направление. |
| * коротко                   | Страница ручного DTMF-набора.                                                                                 |
| * долго                     | Начать/остановить сканирование частот или каналов.                                                            |

| F, затем 1                  | Следующий диапазон F1–F7.                                                                                     |
| F, затем 2                  | Выбрать A/B.                                                                                                  |
| F, затем 3                  | VFO/MR.                                                                                                       |
| F, затем 4                  | Частотомер / Fast Copy.                                                                                       |
| F, затем 5                  | NOAA.                                                                                                         |
| F, затем 6                  | Мощность H/M/L.                                                                                               |
| F, затем 7                  | VOX.                                                                                                          |
| F, затем 8                  | Reverse RX/TX.                                                                                                |
| F, затем 9                  | Вызвать ячейку, заданную 1-CALL. Это не то же самое, что боковая Alarm.                                       |
| F, затем 0                  | Вещательный FM.                                                                                               |
| F, затем *                  | Поиск принимаемого CTCSS/DCS на текущей частоте.                                                              |

На обычном экране F-сочетание означает префикс F, затем вторую клавишу. В FM-приёмнике значения F+1/F+2/F+3 другие: VFO/MR, автоматический поиск с записью, ручной поиск. Эти контексты нельзя смешивать. Боковые назначения — исходные из M1; реальные станции могут быть перенастроены программой.

## Переходы и процедуры

- **VFO:** цифровой набор частоты RX либо шаг ▲/▼. **MR:** номер заполненной ячейки либо ▲/▼. Основной канал отмечает стрелка. Переключение режима и A/B — разные действия.
- **Настройка:** M → номер пункта или ▲/▼ → M → значение ▲/▼ → M сохраняет. EXIT во время редактирования отменяет черновик.
- **Память:** M → 13 → M → номер 001–200 → M → `SURE?` → M. Сохраняются частота и параметры канала. Доступно также копирование MR в другую ячейку. `CH-xxx` — занятая, `xxx` — пустая.
- **Удаление:** M → 50 → M → номер → M → `SURE?` → M. EXIT до окончательного подтверждения не удаляет канал.
- **Сканирование:** долго *; в VFO перебираются частоты с STEP, в MR — члены выбранного S-LIST. EXIT, PTT или долго * прекращают поиск. TO возобновляет через 5 с, CO после исчезновения несущей, SE заканчивает на обнаруженном сигнале.
- **Списки:** 25/26 меняют членство текущего канала. 31 выбирает список 1 или 2. 32/33 просматривают его; пустой отображается как NULL. Приоритеты из компьютерного программирования не следует выдавать за настройку через 32/33.
- **Тоны:** пункты 04/05 относятся к RX, 06/07 — TX. DCS и CTCSS — варианты фильтра, не шифрование. Несовпадение RX-тона может закрыть звук при заметной несущей. Monitor помогает это диагностировать.
- **TDR:** 17 = OFF/CHAN_A/CHAN_B; DW обозначает наблюдение за двумя строками и выбранный канал передачи. Это не два одновременно звучащих независимых приёмника.

## Ограничения реконструкции

В руководствах подтверждён цифровой ввод, но не описаны все промежуточные разряды, таймауты и округление при конкретном STEP. Поведение ввода/времени в тренажёре должно обозначаться как учебное допущение. Аналогично вычисляемая сила виртуальной станции и пороги SQL не являются калибровкой приёмника. Для изучения настоящего экземпляра следует сверить его аппаратную и заводскую программную ревизию: одинаковая надпись UV-K5(8) не доказывает идентичность всего поведения.
