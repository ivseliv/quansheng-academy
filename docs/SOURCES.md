## Расхождения и принятые решения

- W1 ошибочно называет F + * запуском обычного сканирования в пояснении S-LIST. M1/M3 однозначно: долгое * — частоты/каналы; F + * — поиск CTCSS/DCS. Использована брошюра.
- W1 противоречиво описывает знак OFFSET. Используется формула M1: ADD означает TX = RX + OFFSET, SUB означает TX = RX − OFFSET.
- W1 описывает W/N как максимальную девиацию 12,5/25 кГц. Это неточно: таблица M1 различает полосу канала 12,5/25 кГц и максимальную девиацию ±2,5/±5 кГц. В обучении эти величины разделены.
- RP-STE различается: M1/M3 дают OFF/ON, W1 — интервалы до 1000 мс, C1 — OFF и 100–900 мс. Поведение этой функции не моделируется; нельзя заявлять диапазон одного источника универсальным для всех ревизий.
- C1 содержит `BANDS_NOLIMITS` для модификаций 18–1300 МГц и использует его в общих возможностях драйвера. Эти границы не являются возможностями выбранной заводской модели. Основной профиль ограничен диапазонами M1/M3; 76–108 МГц относится к отдельному вещательному FM-приёмнику.
- Граница F2/F3 в C1 — 137 МГц, в брошюре — 136 МГц. Выбран опубликованный в M1/M3 вариант 136 МГц; нельзя выдавать это за исследование всех аппаратных ревизий.
- Точное время распознавания долгого нажатия, задержки каждого сканируемого шага, квантование SQL в дБм, поведение неполного цифрового ввода и пограничное округление частот брошюра не определяет. Эти тайминги и числовые модели в приложении — учебные допущения, не измеренные характеристики устройства.
- В приложении используется ввод шести цифр `300150` для 300.150 МГц; дробная часть выбранного STEP сохраняется при перестройке стрелками. Сам факт ввода цифрами подтверждён руководством, а шестизначное завершение и обработка промежуточного ввода выбраны для этой учебной реализации.
- Драйвер CHIRP принимает несколько семейств OEM и также отдельные пользовательские версии. Совместимость конкретной новой аппаратной ревизии с драйвером не следует из похожего корпуса. Тренажёр учит подготовке и работе с копией настроек, не прошивке радиостанции.

## Учебные допущения

Станции, сила сигнала, шум, расписание передач и реплики созданы для обучения. «Речной канал около Долгопрудного», 300.150 МГц, — сценарий по запросу пользователя; никаких реальных переговоров или подтверждения действующей службы на этой частоте проект не содержит.

Звуки синтезируются локально. PTT меняет только состояние симулятора. Нет радиопередачи, доступа к микрофону, последовательному порту, SDR или реальной рации. Экспорт учебных данных не является образом EEPROM, пригодным для прошивки.

Функции, у которых нет полной модели, должны открывать явную справку «не реализовано», а не создавать видимость работающего радиопротокола. Перечень доступного поведения сверяется с README и интерфейсом; полная таблица заводского меню в [CONTROL_MAP.md](CONTROL_MAP.md) сама по себе не означает реализацию всех 51 функций.
