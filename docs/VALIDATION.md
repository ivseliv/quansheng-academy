Проверено локально на macOS, Node.js 22.22.3, 4 ноября 2026 года.

- `npm run build`: TypeScript и производственная Vite-сборка проходят.
- `npm test`: 78 автоматических тестов в пяти файлах проходят.
- Все 32 задания: исходное состояние не засчитывается, сценарий решается через события кнопок/регулятора; файловые задания проверяют реальное содержимое JSON/CSV.
- Ядро: VFO/MR, A/B, допустимые частоты и точные дробные шаги, черновик меню/отмена/сохранение, SURE для записи/удаления/сброса, пустые и неверные ячейки, полные копии параметров, RX/TX-тоны, W/N, AM, Reverse, блокировка, подсветка, PTT, завершение поиска тонов.
- Эфир: передача/тишина, SQL и тоновые фильтры, Monitor, один приёмный тракт Dual Watch, сканирование частот и отдельных списков памяти, TO/CO/SE, направление и остановка.
- Данные: восстановление параметров и памяти, очистка временного PTT/сканирования при загрузке, безопасная обработка повреждённого localStorage, отсутствие мутации входного состояния.
- React/jsdom: питание и громкость, прохождение урока, цифровой ввод, сохранение после повторного монтирования, клавиатурные сочетания, долгие и мультисенсорные нажатия, отпускание PTT при потере фокуса/отмене касания, фактические файлы экспорта, справка и раздельное хранение режимов.
- Локальный Vite-сервер ответил `HTTP 200` на `http://127.0.0.1:5173/`.
- После обновления тестовых зависимостей npm сообщает 0 известных уязвимостей.

## Граница проверки

Средство управления браузером отключено в настройках Work (`Local browser use is disabled in Work settings`). Поэтому не выполнены визуальный осмотр в браузере, проверка реального сенсорного устройства и прослушивание Web Audio. DOM-тесты проверяют обработчики pointer/keyboard, состояния и структуру, но не подменяют эти проверки. Сопоставление модели с физической радиостанцией также не проводилось; источники и допущения перечислены в SOURCES.md.

## Быстрая ручная приёмка

1. Запустить `npm run dev`, включить питание, поднять громкость, включить звук.
2. В свободном режиме набрать `300150`; услышать синтетические сигналы приёма и увидеть вымышленные реплики во вкладке «Эфир».
3. M → M → 9 → M → EXIT: звук закрыт на слабой несущей; SQL=2 возвращает приём.
4. M → 13 → M → 012 → M → M → EXIT: канал появляется в памяти; F → 3 → 012 вызывает его. Перезагрузка сохраняет запись.
5. Удержание * запускает поиск. F → * запускает другой режим — поиск тонов. F/# удержанием блокирует клавиатуру; боковые органы остаются доступны.
6. На узком окне доступны крупные сенсорные клавиши, раскрывающаяся краткая задача и боковая программа через кнопку книги.
