# Quansheng Academy

Локальный интерактивный тренажёр заводской Quansheng UV-K5 / UV-K5(8): корпус с работающими клавишами, модель состояния приёмника, вымышленный эфир и практические задания. Интерфейс на русском языке. React, TypeScript, Vite; серверная часть, аккаунт и API-ключи не нужны.

[Открыть тренажёр в браузере](https://ivseliv.github.io/quansheng-academy/)

На опубликованном сайте настройки и прогресс сохраняются в браузере. Данные с локального адреса не переносятся автоматически.

## Запуск на macOS

Нужен Node.js **22.22.2 или новее (либо 24.15+)** с npm. В Терминале:

```sh
cd quansheng-academy
npm install
npm run dev
```

Откройте адрес, напечатанный Vite, обычно **http://127.0.0.1:5173**. Если порт занят, Vite выберет следующий. Остановка сервера — `Ctrl+C` в Терминале. Сеть нужна для первоначальной установки зависимостей; само приложение работает локально, без облачных сервисов и внешних запросов.

```sh
npm test          # автоматические проверки
npm run build    # TypeScript + сборка в dist/
npm run preview  # просмотр собранной версии, обычно порт 4173
```

Не открывайте `dist/index.html` через `file://`: используйте локальный сервер. Для повторяемой установки с готовым `package-lock.json` можно применять `npm ci`.

## Первое знакомство

1. Включите рацию нажатием на ручку сверху. На настоящем устройстве её поворачивают через щелчок.
2. Установите громкость ползунком. Для аудио тренажёра отдельно включите звук в интерфейсе: браузер требует действие пользователя перед воспроизведением.
3. `F → 3` переключает выбранную строку между VFO и MR; `F → 2` выбирает A или B.
4. В VFO наберите `3 0 0 1 5 0`: получится **300.150 МГц**.
5. `M → M → 2 → M → EXIT` устанавливает **SQL = 2**. Первое M открывает пункт 01 SQL, второе — его значение.

Это условный «Речной канал около Долгопрудного». Все станции и реплики придуманы; приложение не воспроизводит реальные переговоры и не подтверждает действующую службу на этой частоте.

## Управление

Клавиши корпуса доступны мышью и касанием. Обычное нажатие выполняется при отпускании; удержание от **0,65 секунды** вызывает долгую функцию. Это выбранный тайминг тренажёра, а не измерение аппаратной прошивки. Функции F вводятся последовательно: нажать F, затем вторую клавишу. На клавиатуре компьютера можно также удерживать F и нажать цифру.

| Клавиатура компьютера | Орган рации                                   |
| --------------------- | --------------------------------------------- |
| `0`–`9`               | Цифровые клавиши                              |
| `M` или `Enter`       | M / MENU                                      |
| `Esc`                 | EXIT                                          |
| `↑` / `↓`             | Стрелки                                       |
| `F` или `#`           | F / блокировка                                |
| `*`                   | SCAN; удержание запускает/останавливает поиск |
| `Пробел`              | PTT, пока клавиша удерживается                |
| `Q`                   | Боковая SK1                                   |
| `E`                   | Боковая SK2                                   |
| `P`                   | Питание                                       |

Поле ввода или список в интерфейсе имеет приоритет над управлением рацией с клавиатуры. Удержание F/# блокирует или разблокирует цифровую панель. Боковые клавиши продолжают работать. Справка по клавише объясняет короткое, долгое и составное нажатие; справка по пункту меню объясняет смысл параметра.

Самые полезные заводские действия:

| Действие                            | Последовательность                              |
| ----------------------------------- | ----------------------------------------------- |
| Изменить пункт меню                 | M → номер → M → значение стрелками → M          |
| Отменить правку                     | EXIT; долго EXIT — основной экран               |
| Последний пункт                     | Долго M                                         |
| Сохранить канал                     | M → 13 → M → ячейка 001–200 → M → SURE? → M     |
| Удалить канал                       | M → 50 → M → ячейка → M → SURE? → M             |
| Сканировать                         | Долго *; EXIT останавливает                     |
| Выбрать список                      | Меню 31 S-LIST                                  |
| Добавить текущий канал в список     | Меню 25 S-ADD1 или 26 S-ADD2                    |
| Открыть шумоподавитель для проверки | Коротко SK1, ещё раз — выключить Monitor        |
| Искать CTCSS/DCS                    | F → *; это другой поиск, не сканирование частот |

## Обучение и свободный режим

В учебной программе восемь глав по четыре практические задачи:

1. Органы управления и чтение экрана.
2. VFO, MR и выбор частоты.
3. Шаг частоты и настройки приёмника.
4. Память каналов.
5. Сканирование эфира.
6. Два канала и Dual Watch.
7. Поиск и устранение ошибок.
8. Подготовка к работе с CHIRP на компьютере.

Задания проверяют состояние модели: например, конкретную частоту, сохранённую ячейку, отключённый RX-тон или обнаруженный сигнал. Кнопка подсказки постепенно раскрывает цель, нужный пункт и последовательность. «Почему это работает?» объясняет теорию. История действий помогает восстановить, что изменилось. Начало задачи подготавливает её исходные условия: текущая учебная конфигурация может измениться.

В свободном режиме можно исследовать рацию без заданий и вызывать контекстную справку. Виртуальные станции передают периодически, поэтому отсутствие звука может означать паузу в эфире. Панель диагностики помогает различить тишину, высокий SQL, несовпадение тона, неправильную модуляцию и нулевую громкость.

## Память и резервные копии

Параметры рации, каналы памяти и учебный прогресс хранятся в `localStorage` этого браузера. Они сохраняются после перезагрузки страницы; другой браузер, другой порт или очистка данных сайта дают отдельное хранилище. Приватное окно может удалить данные при закрытии.

Резервная копия JSON относится только к тренажёру. Она **не является CHIRP `.img`**, дампом EEPROM или файлом для загрузки в настоящую рацию. Учебная таблица CSV также не заменяет исходный образ устройства. В CHIRP сначала читают свою рацию через **Download From Radio** и сохраняют исходный `.img`; CSV импортируют в открытый образ. Приложение не подключается к USB/serial и не выполняет программирование устройства.

## Что моделируется

Питание и громкость; A/B; VFO/MR; цифровой ввод частоты и STEP; SQL; W/N; раздельные RX/TX CTCSS/DCS; сохранение и удаление 200 каналов с подтверждением; два списка памяти; сканирование VFO и MR с TO/CO/SE; Dual Watch; Monitor; ручная блокировка; фонарь; подсветка; сигналы клавиш; мощность как параметр канала; OFFSET и Reverse; вызов 1-CALL; отображение MR; AM в авиационном диапазоне; поиск тонов; подтверждаемый сброс. Параметры передачи меняют только учебное состояние.

Модель эфира рассчитывает периодические несущие, разные уровни сигнала, шум и совпадение тонов. Звук синтезируется в браузере; это простые звуковые эффекты, не аудиозаписи переговоров. Приёмник один: Dual Watch не воспроизводит две станции одновременно.

## Границы модели

- Базовая карта соответствует заводским брошюрам 2023 года; это не эмуляция процессора и не гарантия идентичности всех новых аппаратных ревизий. Egzumer, IJV и F4HWN не используются.
- Начальные частоты, учебные каналы и настройки задач подготовлены для занятий. Это не точная копия содержимого EEPROM новой рации из коробки.
- Все 51 названия меню доступны в справочнике. Полной модели DTMF, скремблера, Fast Copy, вещательного FM, NOAA, VOX, Cross-band, батарейной экономии, аппаратной автоблокировки, хвостовых протоколов, голосовых сообщений и радиообмена нет. Неподдерживаемый пункт сообщает об этом явно.
- PTT, 1750 Гц и тревога — исключительно локальная имитация. Передатчик, микрофон, реальные экстренные вызовы, Air Copy и доступ к радиоустройству отсутствуют.
- Ввод шести цифр, задержка долгого нажатия, скорость сканирования, численные пороги SQL и ухудшение качества при несовпадении W/N — учебные допущения. STEP сохраняет дробные кГц; 12.5 кГц не округляется до 12 кГц.
- Частота 300.150 МГц включена как учебная цель, а не рекомендация для реальной передачи. География названия сценария не участвует в расчёте распространения сигнала.
- Имя канала в заводском профиле задаётся компьютерным ПО. Меню VOL показывает условное напряжение батареи; громкость изменяется ручкой.

## Устройство проекта

```text
src/components/   корпус, LCD, клавиши и контекстная справка
src/model/        типы, чистая машина состояний, определения меню, проверки
src/air/          детерминированный вымышленный эфир и звуковые эффекты
src/lessons/      главы, исходные условия и предикаты выполнения задач
src/App.tsx       режимы, инструктор, хранение и связывание интерфейса
docs/             источники, карта управления, проверка вертикального среза
```

Частоты в модели представлены целыми герцами. Переходы выполняет `radioReducer(state, action)`; время подаётся явным событием `TICK`, поэтому поведение можно тестировать без браузера и без настоящего ожидания. Представление не меняет частоты и память напрямую.
